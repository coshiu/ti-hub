How to save your changes in Chrome
Option 1 Save Progress → reopen same file
  1. Click Save Progress in the header — your work is saved to Chrome's local storage instantly.
  2. Next time you open this same file in Chrome, all your edits, checkboxes, and filled fields will be automatically restored.
  3. Note: Local storage is tied to this file's location on your computer. Moving or renaming the file will start fresh.
Option 2 Download → replace your file
  1. Click Download — Chrome will save a new copy of the file with all your current edits baked in.
  2. Find the downloaded file in your Downloads folder.
  3. Replace your original file with the new download, or rename it to keep a version history.
  4. Open the downloaded file in Chrome to continue — your edits will already be there.
Option 3 Chrome keyboard shortcut
  1. Press Ctrl + S (Windows) or ⌘ + S (Mac) while the file is open in Chrome.
  2. In the Save dialog, choose "Webpage, HTML Only" and save over your existing file.
  3. Note: This saves the page's current visual state but may not capture all dynamic edits — the Download button above is more reliable.
Best practice: Use Save Progress while actively working, and Download at the end of each session to keep a portable backup you can share or move between computers.
